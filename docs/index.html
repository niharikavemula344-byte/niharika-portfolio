01

Python · Flask · LangChain · FAISS

DocuMind AI

An intelligent PDF question-answering application that extracts document content and produces context-aware answers from the uploaded file instead of relying on generic responses.

The system processes PDF pages with PyMuPDF, divides the text into searchable chunks and stores semantic embeddings in a FAISS vector index. LangChain retrieves the most relevant passages for each question, while the Flask interface manages file upload, document processing and conversational results. This project demonstrates retrieval-augmented generation, vector search, backend integration and document-aware AI.

Tools used: Python, Flask, LangChain, FAISS, PyMuPDF, document chunking, vector embeddings, HTML, CSS and JavaScript.

02

Python · Flask · BLIP · OpenCV

Vision AI

A computer vision application that interprets uploaded images and generates meaningful natural-language descriptions of the visible scene and objects.

Images are validated and preprocessed with Python and OpenCV before being passed to a deep-learning captioning pipeline. The BLIP model connects visual features with language generation to return readable captions through a Flask web interface. The modular structure separates image processing, model inference and presentation, making the application easier to test, maintain and extend.

Tools used: Python, Flask, BLIP, PyTorch, OpenCV, Pillow, NumPy, HTML, CSS and JavaScript.

03

Python · OpenCV

Face Recognition System

An offline computer vision system that identifies human faces in images and video frames using efficient preprocessing and a pre-trained Haar Cascade classifier.

The application converts frames to grayscale, improves input consistency and applies OpenCV's detection pipeline to locate faces at multiple scales. Detected regions are marked with clear bounding boxes for immediate visual feedback. The work builds practical understanding of camera input, frame-by-frame processing, detection parameters and real-time computer vision while remaining fast enough to run locally.

Tools used: Python, OpenCV, Haar Cascade classifier, NumPy, image preprocessing and live camera frame processing.

05

HTML · CSS · JavaScript · Local Storage

Attendance Calculator

A responsive academic utility that instantly calculates current attendance and shows how many classes a student can miss or must attend to reach a target percentage.

The application accepts total and attended classes, validates incorrect input and calculates the live attendance percentage using clear client-side logic. It performs forward calculations to estimate the classes required to reach a chosen target, providing practical decision support rather than displaying only a percentage. Responsive styling keeps the calculator usable on mobile and desktop, while browser storage can retain recent values without requiring a backend service.

Tools used: HTML5, CSS3, JavaScript, DOM manipulation, form validation, localStorage, Git, GitHub and GitHub Pages.
